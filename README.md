# Skyhop – last-minute flight escapes

Responsive flight discovery and booking website built with HTML, CSS and vanilla JavaScript (frontend only, no build step).

**Live demo:** https://dhilakesh2006.github.io/skyhop-flight-booking/

## Features
- Autocomplete search, theme tabs and filters (trending, hidden gems, closing soon, price, flight time)
- Live fare map linked to the destination list
- Photo galleries, skeleton loaders, toast notifications
- Cart drawer with quantity steppers, promo code `SKY10`, fee breakdown, undo and demo checkout
- Log in / Sign up demo and a timed sign-up prompt
- Scroll animations, counters, FAQ accordion, hero slideshow, mobile menu

## Run locally
Open this folder in VS Code and use the Live Server extension on `index.html`, or run `python -m http.server 5500`.
Keep `index.html` and the `images/` folder together.

## Notes
Fares, flights and reviews are generated sample data. No payments are taken and nothing is sent to a server.
